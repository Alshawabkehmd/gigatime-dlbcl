## Not included (get from DLBCL-Morph)
- H&E and IHC images and patches (needed only for `full` mode — re-running GigaTIME).
- `Cells/cell_shapes.csv` (nuclear geometry, ~356 MB; used for the published morphology baseline).

Download: https://www.cancerimagingarchive.net/collection/dlbcl-morphology/ (TCIA) or the
links at https://github.com/stanfordmlgroup/DLBCL-Morph.

## Column definitions
See `DATA_DICTIONARY.md`. The code renames DLBCL-Morph columns as follows:
`patient_id→case_id`, `OS→os` (years), `Follow-up Status→event` (1 = death), `HANS→coo`,
`IPI Score→ipi_score`, `IPI Risk Group (4 Class)→ipi_group`, `MYC IHC→myc_ihc`, `BCL2 IHC→bcl2_ihc`.

## Feature table format
One row per patient. `case_id` matches `patient_id` in the clinical file. For each of the 21
virtual channels: `<channel>_mean`, `<channel>_std` (spread between patches), `<channel>_p90`,
`<channel>_posfrac` (fraction of pixels > 0.5). Values are 0–1. Generated by notebook Section 4
from 30,151 H&E patches at native magnification with GigaTIME commit `acc49b2`.

## Load in Python
```python
import pandas as pd
base = "https://raw.githubusercontent.com/Alshawabkehmd/gigatime-dlbcl/main/data/"
clinical = pd.read_csv(base + "clinical_data_cleaned.csv")
features = pd.read_csv(base + "gigatime_case_features_rich.csv")
df = features.merge(clinical, left_on="case_id", right_on="patient_id")
```
