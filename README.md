Reproducible code for applying **GigaTIME** — a foundation model that translates routine H&E
into 21 virtual multiplex-immunofluorescence (mIF) channels — to diffuse large B-cell lymphoma
(**DLBCL-Morph**, 209 Stanford tissue-microarray cases). GigaTIME was trained only on solid
tumors, so this is an explicit **out-of-distribution feasibility study**.

## Questions and answers

| Question | Result (n = 170 patients, 58 deaths) |
|---|---|
| Is the virtual output biologically plausible? | **Partly yes.** CD20 is high (0.53, 4th of 21 channels) and cytokeratin low (0.18); T-cell and myeloid markers co-vary (r = 0.69, 0.81); CD20 vs CK r = −0.65. |
| Does it recover cell-of-origin? | **No.** Out-of-fold AUC 0.56. |
| Does it predict overall survival? | **No.** 0 of 84 features survive FDR; cross-validated signature C-index 0.43 (0.40–0.46 over 5 splits), inside the range produced by shuffled outcomes (95 % null 0.39–0.58; p = 0.15) — no signal. IPI C-index 0.65, clinical model 0.66 on the same patients. With 58 deaths, only effects of HR ≥ ~1.44 per SD could be detected. |
| Do double-expressor (MYC ≥40 %, BCL2 ≥50 %) tumors differ? | **Yes, but not as an immune phenotype (exploratory).** They differ along **one** virtual-composition axis (PC1 p = 0.0003, COO-stratified permutation p = 0.001; holds in non-GCB only and without double-hit cases). Adjusting for any one of DAPI, CD138, caspase-3 or **cytokeratin** removes it, and it tracks MYC (p = 7×10⁻⁸) far more than BCL2. Most likely MYC-associated morphology read by a solid-tumor model, **not** an immune-cold microenvironment. |

All numbers are regenerated by the notebook and checked against
[`results/expected_results.json`](results/expected_results.json).

results (~1 min, data included), or leave the default `"synthetic"` to just check the code runs.

## Three modes (set in notebook Section 1)

| `MODE` | Reproduces | Needs | Runtime |
|---|---|---|---|
| `synthetic` | Code path only (figures stamped *SYNTHETIC*) | nothing | ~2 min CPU |
| `features` | All statistics and figures | nothing extra — data included in `data/` | ~1 min CPU |
| `full` | GigaTIME inference on 30,151 H&E patches, then everything | GPU, Hugging Face access to `prov-gigatime/GigaTIME`, DLBCL-Morph patches | ~1–2 h on a T4 |

## Reproducibility

- **Fixed settings** in [`gtdlbcl/config.py`](gtdlbcl/config.py): seed 17, 5-fold CV, elastic-net Cox (penalty 0.1, L1 ratio 0.5), BH-FDR 0.05, 1,000 permutations, 2,000 bootstraps.
- **Pinned model code:** GigaTIME at commit `acc49b2`.
- **Pinned packages:** [`requirements.txt`](requirements.txt); each run writes `outputs/environment.json`.
- **Verification:** notebook Section 9.1 prints MATCH/DIFF for the key results in [`results/expected_results.json`](results/expected_results.json). GitHub Actions re-runs the real analysis on every push and fails on any difference — except the two slow permutation nulls (Sections 7.7 and 7.8), which are checked only when the notebook is run with the published settings.
- **Tests:** [`tests/`](tests/) check the schema, the double-expressor definition, determinism, recovery of a planted signal, and absence of a false survival signal on synthetic data. They run on every push (GitHub Actions).
- **Inference detail that matters:** patches are processed at native size (224 px). Upscaling to 512 px makes virtual CD20 vanish and cytokeratin appear.

## Notes for readers of earlier drafts
- **Independent audit (Oct 2026).** An external review found, and we confirmed: `HANS` is coded **1 = GCB** (the data dictionary had it reversed); double-expressors are 76 % non-GCB, not 22 %. The 12 "significant channels" are one compositional axis driven partly by cytokeratin, so the earlier "immune-cold" reading is withdrawn. A C-index below 0.5 is within chance (full-pipeline permutation), so "ranks risk backwards" is withdrawn too. Permutations are now stratified by cell-of-origin. Notebook sections 7.7, 8.2 and 8.4 contain these analyses.
- Virtual CD20 is the **4th**-highest channel cohort-wide (after DAPI, PD-1 and cleaved caspase-3); it was the top channel only in the single-patch self-test.
- The likelihood-ratio test for added value depends on the cross-validation split (p 0.003–0.18 across 5 splits) and is not valid inference, because the score is built from the same outcomes; the score's hazard ratio is below 1 in every split. Read as no added value.
- The published morphology C-index (0.635) is optimism-corrected in-sample, so it is not directly comparable with out-of-fold values.

## Limitations
Single tissue-microarray cohort; virtual stains with no ground-truth mIF; solid-tumor model used without retraining; 21 double-expressor cases; no external validation yet.
